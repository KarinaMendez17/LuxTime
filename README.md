# LuxTime ⌚

![LuxTime Banner](/image/watch-banner.webp)

**LuxTime** es un sitio web de relojería de lujo que muestra la colección de relojes artesanales de la marca, con diseño responsivo y experiencias interactivas para el usuario.

## 📝 Wireframes

Los diseños iniciales del sitio que muestran la estructura y disposición de cada página antes de aplicar estilos y colores finales.

![LuxTime Banner](/image/planeacionluxtime.webp)

## 🔗 Enlace al sitio web

[LuxTime en Netlify](https://luxtime-dkmdj1.netlify.app/)

## 📂 Estructura del proyecto
```text
    Luxtime/
    ├─ index.html # Página de inicio
    ├─ pages/
    │ ├─ catalogo.html # Catálogo de relojes
    │ ├─ nosotros.html # Historia y filosofía de la empresa
    │ ├─ contacto.html # Formulario de contacto
    │ └─ detalles/ # Detalles de cada reloj (20 en total)
    ├─ css/
    │ ├─ style.css # Estilos generales
    │ ├─ home.css # Estilos para la página de inicio
    │ ├─ catalogo.css # Estilos para catálogo
    │ ├─ nosotros.css # Estilos para nosotros
    │ └─ contacto.css # Estilos para contacto
    ├─ image/ # Imágenes del sitio
    └─ video/ # Videos
```

## 💻 Tecnologías usadas

- **HTML5** – Estructura semántica y accesible.
- **CSS3** – Diseño responsivo con Flexbox y Grid.
- **Media Queries** – Adaptación a distintos tamaños de pantalla.
- **Netlify** – Despliegue y hosting del sitio web.

## 📌 Características

- **Inicio:** Banner interactivo, secciones destacadas de productos.
- **Catálogo:** Listado de relojes con estado de stock, botones de detalles.
- **Nosotros:** Historia, misión, visión, logros, línea del tiempo y galería multimedia.
- **Contacto:** Formulario funcional, información adicional y enlaces a redes sociales.
- **Footer:** Información de contacto, derechos reservados y autor del desarrollo.

## 🌐 SEO y Redes Sociales

- Títulos y descripciones específicas para cada página.
- Imágenes representativas para previsualización en redes sociales.
- Palabras clave relacionadas con relojería y productos de lujo.
